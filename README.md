## 🤖 Current AI Project

### 🎬 AI YouTube Video Automation Pipeline

Currently developing an **AI-assisted YouTube video automation pipeline** that automates the workflow from **topic → content → media → video → metadata → scheduling → YouTube publishing**.

#### ✨ Key Capabilities

* 🧠 **AI Content Generation** using Claude API
* 🖼️ Configurable **AI image generation** providers
* 🎙️ Configurable **AI voice/narration** providers
* 🎞️ Automated video composition using **FFmpeg**
* 📱 Supports both **Long-form videos and YouTube Shorts**
* 📝 Automated titles, descriptions and tags
* 📅 Scheduled publishing and persisted job state
* ▶️ OAuth-based YouTube uploads
* 🔄 Retry, recovery and resumable upload handling
* 🔔 Job completion and failure notifications
* 📊 Monitoring, quality checks and approval controls
* 💰 Cost limits and operational controls
* 🧪 **119 automated tests** currently passing

The project is currently at a **Production-Readiness Prototype** stage, with live provider qualification and deployment hardening as the next major milestones.

**Pipeline:**

```text
Topic
  ↓
AI Content Generation
  ↓
Script + Scenes + Metadata
  ↓
Image / Voice Generation
  ↓
FFmpeg Video Composition
  ↓
Quality Checks
  ↓
Scheduling
  ↓
YouTube Upload
  ↓
Monitoring & Notifications
```
